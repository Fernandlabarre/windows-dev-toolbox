# Historique des versions

Les changements notables sont regroupés dans ce fichier. Le projet suit une
numérotation sémantique à partir de sa première version publique.

## 1.0.0 — 12 novembre 2026

- Publication du lanceur Windows et des outils Git, Python et PowerShell.
- Ajout du gestionnaire de serveurs locaux et du centre de tests.
- Ajout de l'analyse d'espace et de l'export filtré d'un projet.
- Ajout du contexte Visual Studio Code et de l'assistant Ollama local.
- Validation sous Windows PowerShell 5.1, PowerShell 7, Python et Node.js.
- Documentation des limites de sécurité et de l'architecture des processus.
