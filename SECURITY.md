# Sécurité

## Signaler un problème

Pour une vulnérabilité, utilise le bouton **Report a vulnerability** dans
l'onglet **Security** du dépôt. Ce canal reste privé jusqu'à la résolution.

N'ouvre pas d'issue publique contenant un jeton, une clé, un chemin personnel,
un fichier de configuration ou toute autre donnée confidentielle. Pour un bug
sans donnée sensible, une issue GitHub classique convient.

## Périmètre

La version `1.x` est maintenue. Le projet est prévu pour un usage local sous
Windows. Il ne doit pas être exposé comme service réseau public.

Les filtres de chemins et de secrets réduisent les risques de divulgation, mais
ne remplacent pas une vérification humaine avant le partage d'un export ou d'un
journal.
